0x15. C - File I/O

This project covers file input and output operations in C using system calls.

Files

- "main.h" - Contains all function prototypes.
- "0-read_textfile.c" - Reads a text file and prints its contents.
- "1-create_file.c" - Creates a file and writes text into it.
- "2-append_text_to_file.c" - Appends text to an existing file.
- "3-cp.c" - Copies the contents of one file to another.
- "100-elf_header.c" - Displays information from an ELF file header.

Concepts

- File descriptors
- Opening and closing files
- Reading and writing files
- File permissions
- System calls
- ELF file format

Compilation

The C files are compiled using:

"gcc -Wall -Werror -Wextra -pedantic -std=gnu89"
