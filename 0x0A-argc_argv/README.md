# 0x0A. Argc and Argv

This project teaches me how to work with command-line arguments in C. I learn how to use `argc` (argument count) and `argv` (argument vector) to receive and process information passed to a program when it is executed from the terminal. It was a fun project.

I also learn how to print the name of a program, count the arguments passed to it, and print all the arguments, including the program name. I practise using command-line arguments to multiply two numbers, add positive numbers while checking for invalid characters, and calculate the minimum number of coins needed to make change for an amount of money.

The C files in this project are compiled using `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`.
