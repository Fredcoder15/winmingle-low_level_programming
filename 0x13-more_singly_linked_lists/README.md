0x13. C - More singly linked lists

This project contains functions for working with singly linked lists in C.

Files

- "lists.h" - Contains the structure definition and function prototypes.
- "0-print_listint.c" - Prints all the elements of a list.
- "1-listint_len.c" - Returns the number of nodes in a list.
- "2-add_nodeint.c" - Adds a new node at the beginning of a list.
- "3-add_nodeint_end.c" - Adds a new node at the end of a list.
- "4-free_listint.c" - Frees a linked list.
- "5-free_listint2.c" - Frees a linked list and sets the head to NULL.
- "6-pop_listint.c" - Deletes the head node and returns its value.
- "7-get_nodeint.c" - Returns the node at a given index.
- "8-sum_listint.c" - Returns the sum of all the node values.
- "9-insert_nodeint.c" - Inserts a new node at a given position.
- "10-delete_nodeint.c" - Deletes a node at a given position.
- "100-reverse_listint.c" - Reverses a linked list.
- "101-print_listint_safe.c" - Prints a linked list safely, including lists with loops.
- "102-free_listint_safe.c" - Frees a linked list safely, including lists with loops.
- "103-find_loop.c" - Finds the starting node of a loop in a linked list.

Compilation

The files are compiled using:

"gcc -Wall -Werror -Wextra -pedantic -std=gnu89"
