# 0x05 Pointers, Arrays and Strings

This project is about pointers, arrays and strings in C. I learnt how to work with pointers, swap values, find the length of a string, reverse strings and copy strings without using the standard library functions.

The project contains the following files:

0-reset_to_98.c - Changes the value of an integer to 98.
1-swap.c - Swaps the values of two integers.
2-strlen.c - Finds the length of a string.
3-puts.c - Prints a string followed by a new line.
4-print_rev.c - Prints a string in reverse.
5-rev_string.c - Reverses a string.
6-puts2.c - Prints every other character.
7-puts_half.c - Prints half of a string.
print_array.c - Prints elements of an integer array.
string_copy.c - Copies a string.
string_to_integer.c - Converts a string to an integer.
101-keygen.c - Generates a random password.

All files must follow Betty style. Global variables are not allowed, and each file must contain no more than five functions. The function prototypes are declared in main.h.

The programs are compiled using gcc with -Wall -Werror -Wextra -pedantic -std=gnu89.
